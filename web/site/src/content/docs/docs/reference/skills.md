---
title: Skills
description: Reusable instructions the model can load when a task calls for them.
sidebar: { order: 1 }
---

A skill is a text file, `SKILL.md`, with a short description and a body of instructions. Gantry loads a skill into the conversation when its keywords match what you are doing or when the model asks for it, and you can pin a skill to a project so it is always present.

- **Write** one in the Skills page; the editor shows the frontmatter fields Gantry uses.
- **Import** skills written for other tools that follow the same format.
- **Export** a skill as a file to share it.
- **Proposed skills**: when a chat has done something worth repeating, the assistant may propose a skill. You see the text and confirm or discard it; nothing is saved silently.

Skills are plain text you can read and edit at any time, and they never run code.
