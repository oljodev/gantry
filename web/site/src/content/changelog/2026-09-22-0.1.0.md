The first release of Gantry, for Windows and Linux.

## What is in it

**Chat with any model.** Bring a key from Anthropic, OpenAI, Google, xAI or OpenRouter, or point Gantry at Ollama, LM Studio or any other OpenAI-compatible server. Switch models in the middle of a chat. Image, speech, music and video models answer in the conversation too.

**A Code surface.** Open a folder and hand the model a task: it reads the code, edits files, runs your builds and tests in a shell, and every change it makes shows up as a diff you can revert, one file at a time or the whole session. There is a terminal of your own beside it.

**Permissions you choose per chat.** Manual asks before anything happens; Auto-edit lets file edits through; Plan reads and proposes without changing anything; Auto hands the decisions to a guard model and shows you each one. Guardrails for dangerous commands and sensitive files sit above all four.

**Connectors.** 67 of them in the catalogue, installed one at a time with OAuth sign-in where the service offers it, and a model that can suggest one when a task needs it. Web search and page reading work without a key.

**The rest of a workspace.** Artifacts — documents, diagrams, pages and React components, versioned, in a sandboxed panel. Projects with their own instructions, knowledge files and defaults. Skills, memory you can see and edit, incognito chats, and sub agents a model can hand work to.

**Local.** Chats, files and settings are a SQLite database on your machine. Keys are encrypted with a master key kept in your operating system's credential store. Nothing leaves your computer except the requests you make: to the model provider you chose, and to the services you connect.

## Before you install

- Gantry has been used every day on Linux while it was built. The Windows build is new, so anything that misbehaves there is especially worth [an issue](https://github.com/oljodev/gantry/issues).
- The Windows installer is not signed yet: SmartScreen stops it the first time, and **More info → Run anyway** gets past it.
- There is no macOS build yet, and no automatic updates: a new version is a new download from [the download page](https://gantry.oljo.dev/download/).
