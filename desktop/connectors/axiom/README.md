# Axiom

Axiom's hosted server: datasets and APL queries over your event data.

- **Runs:** nothing locally. `https://mcp.axiom.co/mcp`.
- **Needs:** an Axiom account; sign-in happens in your browser through `authorization.axiom.co`, which offers a client-id metadata document as well as dynamic registration.
- **Can reach:** the datasets in the organisation you sign in to — your production events, which is to say your users' activity.
- **Protocol:** verified mechanically when this entry was written (2026-09-12): `401` with a protected-resource document, both registration modes offered. The tool list is discovered at the first connection; nobody here has signed in, so this entry does not claim to know what it contains.
