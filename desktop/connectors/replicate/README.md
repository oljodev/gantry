# Replicate

Replicate's hosted server: find a model, run it, read the prediction.

- **Runs:** nothing locally. `https://mcp.replicate.com/mcp`.
- **Needs:** a Replicate account; sign-in happens in your browser. Replicate publishes no protected-resource document and serves metadata on its own origin, which is the fallback case, with dynamic registration.
- **Can reach:** your Replicate account. **Every prediction is billed to it**, so starting one is the money rule of 17 §6 and is confirmed in every mode.
- **Protocol:** verified mechanically when this entry was written (2026-09-12): `401`, no protected-resource document, dynamic registration on the origin's metadata. The tool list is discovered at the first connection; nobody here has signed in, so this entry does not claim to know what it contains.
