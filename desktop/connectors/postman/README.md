# Postman

Postman's hosted server: collections, requests and environments — and running one.

- **Runs:** nothing locally. `https://mcp.postman.com/mcp`.
- **Needs:** a Postman account; sign-in happens in your browser and the server registers Gantry on the spot.
- **Can reach:** your workspaces and what is in them. **Running a saved request is a real call to a real API**, sent with whatever environment the collection selects — production included, if that is what is selected.
- **Protocol:** verified mechanically when this entry was written (2026-09-12): `401` with a protected-resource document, dynamic registration offered. The tool list is discovered at the first connection; nobody here has signed in, so this entry does not claim to know what it contains.
