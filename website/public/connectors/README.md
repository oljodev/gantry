# Connector logo assets

Put an official, cleared logo here as `<slug>.svg` (or `.png`) and set `logo: '/connectors/<slug>.svg'` on the matching
entry in `src/connectors/data.ts`. Until then the tile shows a monogram in the category tint.

Rules: only assets you have the right to use under that company's brand guidelines; no re-drawn or invented marks;
prefer a single-colour or the vendor's dark/light variants; keep files under 20 KB.
