Watch it work.

An agent in Gantry edits files, runs commands and uses connectors while you watch. Every action is a row in the activity feed. Every risky one waits for your yes.

Edits files
Targeted changes to the folders you add, shown as diffs before and after, revertible.
Runs commands
Builds, tests and scripts in your shell, with output streaming as it happens.
Uses connectors
GitHub, Drive, databases and more, through the same visible tool calls.
Asks first
Four permission modes per chat, from approve-everything to hands-off with a guard model watching.

Connectors, built in.

A curated set ships with the app, from your own files and shell to the services you already use. Nothing installs itself. Every connector is one explicit click away.

What Gantry is.

  • A chat client

    Talk to Claude, GPT, Gemini and Grok models, or anything on OpenRouter, from one place. Projects group chats with their files and instructions.

  • A coding agent

    Works inside your repository with visible diffs and commands, under a permission mode you choose per chat.

  • Connectors

    Local connectors for files and shell, plus MCP servers for the services you use.

  • Your keys

    No subscription. Add your own API keys; they stay encrypted in your OS keychain.

  • Every desktop

    One app for macOS, Windows and Linux, built with Rust and Tauri.

Early, and in the open.

Gantry is under active development. The code is source-available under the Functional Source License, and the repository is private while the first release takes shape.
