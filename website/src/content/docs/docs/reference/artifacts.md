---
title: Artifacts
description: Documents, code, diagrams and small apps a model builds, kept beside the chat.
sidebar: { order: 3 }
---

An artifact is a piece of work large enough to deserve its own panel: a document, a code file, an SVG or diagram, an HTML page, or a small React app.

- Artifacts are **versioned**. Each edit by the model or by you creates a new version; step back at any time.
- Interactive artifacts (HTML, React) run in a **sandbox**: an isolated frame with no access to your files, your keys or the rest of the app, under a strict content policy. Runaway loops are stopped.
- Artifacts belong to the chat that made them and are listed on the project page.
- Export any artifact as a file, or open an interactive one in its own window.
