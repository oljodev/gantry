title: Settings
description: What lives where in Gantry's settings.
sidebar: { order: 4 }
---

| Section | What it holds |
|---------|---------------|
| General | Language, startup behaviour, keyboard shortcuts |
| Appearance | Light, dark or system theme; type size |
| Providers | API keys, default model, custom endpoints |
| Guard | The guard model per provider, and whether Guard is on by default in Auto |
| Guardrails | Paths and commands that always ask, whatever the mode |
| Connectors | Installed connectors, their credentials and per-connector tool tiers |
| Skills | Your skills, imports and exports |
| Memory | What Gantry remembers |
| Data | Where the database and blob folder are, backup and delete |
| Advanced | Logging, developer options |
| About | Version, licence, notices |
