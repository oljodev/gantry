title: Memory
description: Facts Gantry remembers between chats, all of them visible and editable.
sidebar: { order: 2 }
---

Memory is a small table of facts about you and your work, kept locally and shown in full on the Memory page.

- The assistant **proposes** a memory when it notices something worth keeping (a preference, a fact about a project). The proposal appears as a card you can save or dismiss; the chat continues either way.
- Selected memories are added to a chat's context within a fixed budget, most relevant first.
- Every memory can be edited or deleted on the Memory page, and deleted memories sit in a recently-deleted list for a while.

Nothing is remembered without your yes.
