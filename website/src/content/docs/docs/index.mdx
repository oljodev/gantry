Gantry is a desktop AI workspace: a chat client, a coding agent and connectors to the tools you use, in one app that runs on your machine with your own API keys.

## How the docs are organised

- **Start here** takes you from install to a first chat, a project, and the agent's permission modes.
- **Connectors** explains what a connector is, how to install and sign in to one, and how to add an MCP server the catalog does not have.
- **Reference** covers skills, memory, artifacts, settings, where your data lives, and the questions people ask.
