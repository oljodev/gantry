# Gantry

The AI workspace that stays on your machine. A desktop app for macOS, Windows and Linux that
combines a chat client for any model on your own keys, a coding agent that works in your folders
under permissions you set, and an extensible connector (MCP) system, all stored locally.

**Status:** pre-release, being built from the ground up against a written plan. Milestones M0 (the
skeleton: window, theming, typed IPC, CI), M0b (the design system, component library and mock
screens on fixture data) and M1 (the first conversation: an encrypted OpenRouter key, streaming,
stop) are done; see `docs/plan/09-roadmap.md` for what comes next. The previous codebase is on the `archive/gantry-v1` branch.
